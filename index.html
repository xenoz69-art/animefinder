About AnimeFinder

An anime search engine for finding titles you remember

AnimeFinder is an anime search and identification tool that helps users find titles by name or from a screenshot of a scene. It was built for those moments when you remember a character, part of a title, or only have a single image from an anime but don't know its name.

Unlike streaming catalogs, AnimeFinder does not provide or host anime videos. This service focuses on helping you find relevant anime information, such as alternative titles, synopsis, genres, episode counts, airing status, seasons, scores, and scene-match results. Catalog data comes from AniList, while image-based searches are processed through trace.moe.

How It Works

How does AnimeFinder find anime?

1

Pick a search method

Use name search if you know the title or a keyword. Use image search if all you have is a screenshot of a scene.

2

Your request is processed

Name searches go to AniList. Screenshots go to trace.moe to find scene matches and the likely source anime.

3

Review the results

Compare titles, images, genres, episodes, seasons, status, and more before opening an anime's details.

Image search tips: use a screenshot that clearly shows a character or background, avoid images that are too small or covered in text, and try another screenshot if the first result misses.
Understanding Results

What information is available?

Every anime can have more than one title. AnimeFinder shows the available romaji, English, or native titles so you can recognize the series you're looking for even if the name you remember is different.

Result cards can also show the year, episode count, format, genres, status, and score. These values come from third-party services and may change when the source updates its catalog.

FormatTV, Movie, OVA, ONA, Special, and other available formats.
StatusFor example Finished Airing, Currently Airing, or Not Yet Released.
GenreCategories like Action, Comedy, Drama, Fantasy, Romance, and more.
ScoreCommunity scores available from the AniList catalog, not AnimeFinder's own ratings.
FAQ

AnimeFinder FAQ

Is AnimeFinder an anime streaming site?

No. AnimeFinder is an anime search and identification tool. This site does not provide anime video files to watch or download.

Can I search for anime from just a screenshot?

Yes. Pick the Search by Image tab, upload a clear screenshot, then run the image search. Results depend on trace.moe's matching ability.

Where does the anime data come from?

Anime catalog information comes from AniList. Scene search by image uses trace.moe. AnimeFinder combines these into one search interface.

Why can image search results be wrong?

Image search is visual matching. Blurry, cropped, or tiny screenshots — or ones not from a recognized scene — can produce inaccurate matches.

Is AnimeFinder free?

The search features on this site are free to use. Availability still depends on the third-party API services used to process requests.

Does AnimeFinder store my screenshots?

AnimeFinder does not store a gallery of user screenshots. Search images are sent to a third-party matching service as described in the Privacy Policy.
