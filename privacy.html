Privacy Policy

Terakhir diperbarui: 5 September 2026

Pendahuluan

AnimeFinder ("kami") menghargai privasi pengguna ("Anda"). Kebijakan Privasi ini menjelaskan data apa saja yang kami kumpulkan, bagaimana data tersebut digunakan, dan pilihan yang Anda miliki saat menggunakan layanan pencarian anime berbasis nama maupun gambar (screenshot) di situs ini.

Data yang Kami Kumpulkan

  • Kata kunci pencarian — judul atau kata kunci anime yang Anda ketikkan pada fitur pencarian nama.
  • Gambar/screenshot — file gambar yang Anda unggah untuk fitur pencarian berbasis gambar dikirim ke layanan pihak ketiga (trace.moe) hanya untuk keperluan identifikasi adegan anime, dan tidak disimpan secara permanen di server kami.
  • Data teknis dasar — seperti jenis browser dan perangkat, yang dapat tercatat secara otomatis untuk keperluan keamanan dan perbaikan performa.

Bagaimana Data Digunakan

Data pencarian dan gambar yang Anda kirimkan digunakan semata-mata untuk memproses permintaan pencarian melalui API pihak ketiga, yaitu AniList dan trace.moe. Kami tidak menjual, menyewakan, atau membagikan data pribadi Anda kepada pihak lain untuk kepentingan pemasaran.

Layanan Pihak Ketiga

AnimeFinder menggunakan API publik dari AniList dan trace.moe untuk menyediakan hasil pencarian. Penggunaan layanan tersebut tunduk pada kebijakan privasi masing-masing penyedia, dan kami menyarankan Anda membacanya secara terpisah.

Cookie & Penyimpanan Lokal

Situs ini dapat menggunakan penyimpanan lokal browser (local storage) sebatas untuk menyimpan preferensi tampilan, dan tidak digunakan untuk melacak identitas pribadi Anda di situs lain.

Keamanan Data

Kami berupaya menjaga keamanan data melalui praktik teknis yang wajar. Namun, tidak ada metode transmisi data melalui internet yang 100% aman, sehingga kami tidak dapat menjamin keamanan mutlak.

Hak Anda

Anda berhak untuk tidak menggunakan fitur unggah gambar apabila tidak ingin gambar tersebut diproses oleh layanan pihak ketiga. Anda juga dapat menghubungi kami melalui halaman Contact untuk pertanyaan terkait data Anda.

Perubahan Kebijakan

Kebijakan ini dapat diperbarui sewaktu-waktu. Perubahan akan berlaku sejak dipublikasikan di halaman ini.
