Deskripsi Layanan

AnimeFinder adalah alat pencarian anime yang memungkinkan pengguna mencari informasi anime berdasarkan nama judul maupun melalui unggahan screenshot adegan, dengan memanfaatkan API publik dari AniList dan trace.moe.

Penggunaan yang Diperbolehkan

  • Menggunakan layanan hanya untuk keperluan pribadi dan non-komersial, kecuali dinyatakan lain secara tertulis.
  • Tidak menyalahgunakan layanan untuk mengirim permintaan otomatis dalam jumlah besar (scraping/abuse) yang dapat mengganggu kestabilan layanan atau API pihak ketiga.
  • Tidak mengunggah gambar yang melanggar hukum, mengandung konten ilegal, atau melanggar hak pihak lain.

Hak Kekayaan Intelektual

Seluruh judul, gambar sampul (cover), sinopsis, dan data anime yang ditampilkan merupakan milik pemegang hak cipta masing-masing dan disediakan melalui API AniList. AnimeFinder tidak mengklaim kepemilikan atas konten tersebut.

Batasan Tanggung Jawab

Layanan disediakan "sebagaimana adanya" (as is) tanpa jaminan ketersediaan, keakuratan, maupun kelengkapan data secara terus-menerus. Untuk informasi lebih lanjut, silakan lihat halaman Disclaimer kami.
