How to use AnimeFinder

Guide to searching anime by title and screenshot.

What is AnimeFinder?

AnimeFinder is an anime search tool built to help users find a series when they know its name, part of its name, or only have a screenshot of a particular scene. The service combines catalog search with visual search so both kinds of search problems can be solved from a single page.

AnimeFinder is not a streaming site. Its main purpose is to find information and point users to relevant anime data. Catalog information in the results comes from AniList, while screenshot-based search uses trace.moe.

1. Searching anime by name

Open the homepage and make sure the Search by Name tab is active. Enter the title you remember — for example the official title, the English title, or part of the title. Press the Search button and wait for catalog results to appear.

If there are too many results, use more specific words. For example, instead of typing just “Dragon”, add another word you remember from the title. Once results appear, check the poster, year, episode count, format, status, and genres to tell apart similarly named series.

2. Searching anime from a screenshot

If you don't know the anime's title, pick the Search by Image tab. Upload a screenshot that clearly shows a scene. Once the image is selected, press the image search button.

Visual search results can show titles that match the image, including scene info like episode and timestamp when that data is available from the matching service. Visual results aren't always perfect, so use more than one screenshot if the first result isn't convincing.

3. Choosing a good screenshot

  • Use an image that's sharp enough and not too small.
  • Pick a scene showing a character, background, or visual element that's easy to distinguish.
  • Avoid screenshots covered by large watermarks, player menus, or text filling the whole image.
  • If one screenshot produces a poor match, try another scene from the same episode.

4. Understanding the info in results

Each anime card can show several kinds of information. Format describes the release type such as TV or Movie. Status shows the airing state recorded in the catalog. Episodes shows the episode count available in the source data. Genres help describe the story's category. Score is the value provided by the catalog, not a score made by AnimeFinder.

5. Why can data differ?

Anime databases keep changing. Alternative titles can be updated, episode counts can change while a series is still airing, and season or status info can be corrected by the data source. Because AnimeFinder uses third-party services, what you see on the site may differ from older info you've seen before.

Image search privacy

Screenshots used for search are processed through a third-party service that provides image-based anime search. AnimeFinder offers no gallery feature to store user screenshots. Details about data and third-party services are explained in the Privacy Policy.

Information sources

For the anime catalog, AnimeFinder uses AniList. For screenshot-based search, AnimeFinder uses trace.moe. AnimeFinder claims no ownership over the anime data or material from these sources.
